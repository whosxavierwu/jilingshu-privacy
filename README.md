# jilingshu-privacy

GitHub Pages 托管机灵薯对外隐私政策与用户协议，供商店审核员访问（大陆源站 `jilingshu.top` 对海外可能 timeout）。

| 页面 | 地址 | 用途 |
|---|---|---|
| 浏览器扩展隐私政策 | https://whosxavierwu.github.io/jilingshu-privacy/ | Chrome / Edge 商店 |
| iOS App 隐私政策 | https://whosxavierwu.github.io/jilingshu-privacy/app-privacy.html | App Store Connect |
| iOS App 用户协议 | https://whosxavierwu.github.io/jilingshu-privacy/app-terms.html | App 内与审核备注 |

Chrome 与 iOS 不要共用同一页：扩展政策写的是浏览器扩展，App 政策还要覆盖相机、相册和 Safari 扩展。
