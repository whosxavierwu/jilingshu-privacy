# jilingshu-privacy

GitHub Pages 托管机灵薯对外隐私政策与用户协议，供商店审核员访问（大陆源站 `jilingshu.top` 对海外可能 timeout）。

| 页面 | 地址 | 用途 |
|---|---|---|
| 浏览器扩展隐私政策 | https://whosxavierwu.github.io/jilingshu-privacy/ | Chrome / Edge 商店 |
| iOS / Android App 隐私政策 | https://whosxavierwu.github.io/jilingshu-privacy/app-privacy.html | App Store Connect |
| iOS App 用户协议 | https://whosxavierwu.github.io/jilingshu-privacy/app-terms.html | App 内与审核备注 |

浏览器扩展与 App 不要共用同一页：App 政策覆盖 iOS / Android 的相机、相册、云端创作、订阅雷达及推送；Safari 扩展说明仅适用于仍含该扩展的旧版 iOS。

App 政策正文以 `xhs_assist/scripts/app-privacy.html` 为源，两处同步，保留本仓库页首的用户协议链接。2026-11-02 已同步本地源码，尚未发布并核验 GitHub Pages 或国内源站。
